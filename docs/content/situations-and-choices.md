# 상황과 선택지 원본

### 1. 길에 쓰레기가 떨어져 있다
- 주워서 쓰레기통에 버린다. → `행복 +1 / 청결 +3 / 오염 -2 / 질서 +1 / 선 +2`
- 그냥 지나간다. → `변화 없음`
- **내 쓰레기도 옆에 버린다.** → `청결 -3 / 오염 +2 / 질서 -2 / 선 -1`

### 2. 빨간불인데 차가 한 대도 없다
- 초록불이 될 때까지 기다린다. → `치안 +1 / 질서 +2`
- 주변을 확인하고 건넌다. → `질서 -1`
- **차도 없는데 뭘 기다려? 그냥 건넌다.** → `치안 -1 / 질서 -2`

### 3. 누군가 지갑을 떨어뜨렸다
- 주인을 찾아 돌려준다. → `행복 +2 / 치안 +1 / 선 +3`
- 분실물 센터에 맡긴다. → `치안 +2 / 질서 +2 / 선 +2`
- **현금만 빼고 지갑은 돌려준다.** → `치안 -2 / 질서 -2 / 선 -3`

### 4. 버스 정류장에서 누군가 새치기한다
- 줄을 지켜달라고 말한다. → `치안 +1 / 질서 +2 / 선 +1`
- 그냥 넘어간다. → `변화 없음`
- **나도 그 사람 앞에 새치기한다.** → `행복 -1 / 치안 -1 / 질서 -3 / 선 -1`

### 5. 길을 잃은 아이가 울고 있다
- 보호자를 같이 찾아준다. → `행복 +2 / 치안 +1 / 선 +3`
- 안내소나 경찰에게 데려간다. → `행복 +1 / 치안 +2 / 질서 +2 / 선 +2`
- 그냥 지나간다. → `행복 -1 / 선 -1`

### 6. 공원에서 누군가 큰 소리로 음악을 틀고 있다
- 소리를 줄여달라고 부탁한다. → `행복 +1 / 질서 +1 / 선 +1`
- 그냥 참는다. → `변화 없음`
- **내 음악을 더 크게 튼다.** → `행복 -2 / 치안 -1 / 질서 -2`

### 7. 불법 주차된 차 때문에 통행이 어렵다
- 신고한다. → `치안 +2 / 질서 +3`
- 그냥 지나간다. → `변화 없음`
- **차에 '이곳에 주차하지 마시오.'라고 낙서한다.** → `행복 -1 / 치안 -2 / 청결 -1 / 질서 -3 / 선 -2`

### 8. 카페 직원이 거스름돈을 더 줬다
- 더 받은 돈을 돌려준다. → `선 +3 / 질서 +1`
- 아무 말 없이 가져간다. → `질서 -1 / 선 -2`
- **친구에게 오늘 커피값 벌었다고 자랑한다.** → `질서 -2 / 선 -2`

### 9. 지하철에서 자리가 하나 났다
- 노약자에게 양보한다. → `행복 +2 / 선 +3`
- 내가 앉는다. → `변화 없음`
- **누가 앉기 전에 빠르게 자리를 선점한다.** → `행복 -1 / 질서 -1 / 선 -2`

### 10. 친구가 시험에서 부정행위를 하자고 한다
- 거절한다. → `질서 +2 / 선 +1`
- 못 들은 척한다. → `변화 없음`
- 같이 한다. → `질서 -3 / 선 -2`
- **선생님한테 이른다.** → `질서 +3 / 선 +1`

### 11. 분리수거장이 엉망이다
- 직접 정리한다. → `청결 +3 / 오염 -2 / 질서 +1 / 선 +2`
- 관리소에 알린다. → `청결 +2 / 오염 -1 / 질서 +2`
- **이미 엉망이니까 내 쓰레기도 그냥 버린다.** → `청결 -3 / 오염 +3 / 질서 -2 / 선 -1`

### 12. 가까운 거리에 이동해야 한다
- 걸어간다. → `오염 -2 / 선 +1`
- 대중교통을 이용한다. → `오염 -1`
- 차를 타고 간다. → `오염 +1`

### 13. 꽃밭에 들어가면 사진이 잘 나올 것 같다
- 꽃밭 밖에서 사진을 찍는다. → `질서 +1`
- 잠깐 들어가서 사진만 찍는다. → `청결 -1 / 질서 -1`
- **사진도 찍고 꽃도 한 송이 가져간다.** → `청결 -2 / 질서 -2 / 선 -2`

### 14. 동네 하천에 쓰레기가 쌓여 있다
- 정화 활동에 참여한다. → `행복 +2 / 청결 +3 / 오염 -3 / 선 +3`
- 민원을 넣는다. → `청결 +1 / 오염 -1 / 질서 +2`
- 그냥 지나간다. → `변화 없음`

### 15. 일회용품과 다회용품 중 선택할 수 있다
- 다회용품을 사용한다. → `청결 +1 / 오염 -2 / 선 +1`
- 일회용품을 사용한다. → `오염 +1`
- **공짜니까 일회용품을 여러 개 챙긴다.** → `청결 -1 / 오염 +2 / 선 -1`

### 16. 이웃이 무거운 짐을 들고 있다
- 같이 들어준다. → `행복 +2 / 선 +3`
- 도움을 받을 수 있는 사람을 불러준다. → `행복 +1 / 선 +2`
- 그냥 지나간다. → `변화 없음`

### 17. 동네 축제 자원봉사자를 모집한다
- 자원봉사에 참여한다. → `행복 +3 / 청결 +1 / 선 +2`
- 참가자로 축제를 즐긴다. → `행복 +1`
- **아무도 안 볼 때 행사 장식 하나를 가져간다.** → `행복 -1 / 치안 -2 / 질서 -2 / 선 -2`

### 18. 길고양이에게 먹이를 주고 싶다
- 지정된 장소에서 먹이를 준다. → `행복 +1 / 청결 +1 / 질서 +1 / 선 +2`
- 길 한쪽에 사료를 놓아준다. → `청결 -1 / 선 +1`
- 고양이를 쫓아낸다. → `행복 -1 / 선 -1`

### 19. 공용 화장실 바닥에 휴지가 떨어져 있다
- 직접 주워서 정리한다. → `청결 +3 / 선 +2`
- 관리자에게 알린다. → `청결 +1 / 질서 +1`
- **내 휴지도 하나 보탠다.** → `청결 -3 / 질서 -2 / 선 -1`

### 20. 주민들이 공원에 나무를 심고 있다
- 같이 나무를 심는다. → `행복 +2 / 청결 +1 / 오염 -3 / 선 +2`
- 그냥 지나간다. → `변화 없음`
- **방금 심은 나무를 다시 뽑는다.** → `행복 -2 / 청결 -1 / 오염 +2 / 질서 -2 / 선 -3`

### 21. 길거리에서 두 사람이 싸우고 있다
- 경찰에 신고한다. → `치안 +3 / 질서 +2 / 선 +1`
- 주변 사람들과 함께 말린다. → `행복 +1 / 치안 +2 / 선 +3`
- **일단 휴대폰부터 꺼내서 촬영한다.** → `행복 -1 / 선 -2`

### 22. 친구가 다른 사람의 비밀을 알려줬다
- 비밀을 지킨다. → `선 +2`
- 당사자에게 알려준다. → `선 +1`
- **'너만 알고 있어'라며 다른 친구에게 말한다.** → `행복 -2 / 질서 -1 / 선 -3`

### 23. 식당에서 주문하지 않은 비싼 음식이 나왔다
- 직원에게 잘못 나왔다고 말한다. → `질서 +1 / 선 +2`
- 일단 두고 직원을 기다린다. → `질서 +1`
- **서비스라고 믿고 먹는다.** → `질서 -2 / 선 -1`

### 24. 공원 금지구역을 지나가면 지름길이다
- 정해진 길로 돌아간다. → `질서 +2`
- 잠깐 가로질러 간다. → `청결 -1 / 질서 -1`
- **울타리를 넘어 새로운 길을 개척한다.** → `청결 -2 / 질서 -3 / 선 -1`

### 25. 가게에서 누군가 물건을 훔치는 걸 봤다
- 직원에게 알린다. → `치안 +3 / 질서 +2 / 선 +2`
- 모른 척한다. → `치안 -1`
- **나도 슬쩍 하나 챙긴다.** → `치안 -3 / 질서 -3 / 선 -3`

### 26. 갑자기 정전이 발생했다
- 안내에 따라 기다린다. → `치안 +1 / 질서 +2`
- 주변 사람들을 도와준다. → `행복 +2 / 치안 +1 / 선 +3`
- **CCTV도 꺼졌으니 가게 물건을 훔친다.** → `행복 -2 / 치안 -4 / 질서 -4 / 선 -4`

### 27. 폭우로 도로 일부가 침수됐다
- 위험 지역을 신고한다. → `치안 +2 / 질서 +2 / 선 +1`
- 주변 사람들에게 위험하다고 알려준다. → `행복 +2 / 치안 +1 / 선 +2`
- **얼마나 깊은지 직접 들어가 본다.** → `치안 -1 / 질서 -2`

### 28. 행사 때문에 도로가 통제됐다
- 안내에 따라 우회한다. → `치안 +1 / 질서 +2`
- 잠시 기다렸다가 이동한다. → `질서 +1`
- **바리케이드를 옆으로 치우고 지나간다.** → `치안 -2 / 질서 -3 / 선 -1`

### 29. 화재경보가 울렸는데 불은 보이지 않는다
- 안내에 따라 대피한다. → `치안 +2 / 질서 +2`
- 주변 사람들에게도 대피하라고 알려준다. → `행복 +1 / 치안 +2 / 질서 +1 / 선 +3`
- **또 오작동이겠지 하고 무시한다.** → `치안 -2 / 질서 -2`

### 30. 도시 광장에서 정체불명의 상자를 발견했다
- 경찰에 신고한다. → `치안 +3 / 질서 +3`
- 사람들이 가까이 가지 못하게 한다. → `치안 +2 / 선 +2`
- **일단 열어본다.** → `치안 -2 / 질서 -3`
