# 아키텍처 결정 기록 (ADR)

ADR(Architecture Decision Record)은 프로젝트의 주요 기술 결정을 왜 내렸고 어떤 영향이 있는지 남기는 문서입니다. SIM:US에서는 웹·Unity·DB 사이의 계약이나 운영 데이터에 장기적으로 영향을 주는 결정을 기록합니다.

## 작성 방법

1. [작성 양식](template.md)을 복사해 `NNNN-영문-제목.md`를 만들고 이 목차에 추가합니다. 한 문서에 결정 하나를 담습니다.
2. `제안`으로 시작하고 합의하면 `채택`으로 바꿉니다. `채택`은 결정의 상태이며, 구현·검증·배포 범위는 본문이나 연결한 근거에서 확인합니다.
3. 결정을 바꾸면 새 ADR에 변경 이유를 쓰고, 이전 기록을 `대체됨`으로 표시해 서로 연결합니다. 검토 후 접은 제안은 `기각`으로 표시합니다.

과거 결정을 옮겨 적을 때는 작성일과 원결정의 근거를 함께 남깁니다. 상세 동작은 기능 계약, 실행 절차는 운영 가이드, 검증 결과는 검증 보고서에 연결합니다.
