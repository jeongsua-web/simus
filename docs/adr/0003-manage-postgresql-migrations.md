# ADR 0003 — PostgreSQL 스키마를 관리형 마이그레이션으로 적용한다

| 항목 | 내용 |
| --- | --- |
| 상태 | 채택 |
| 기록일 | 2026-11-18 |
| 최초 구현 | 2026-10-20 |

## 배경

신규 DB와 기존 회차·결과가 저장된 DB의 출발 상태가 다르다. 016이 원본 014를 대체하고 015보다 먼저 실행되며, 012는 진행 중인 회차의 콘텐츠를 바꾸므로 별도 승인으로 처리한다. SQL 파일 번호와 적용 여부를 명시적으로 관리해야 한다.

## 결정

`scripts/db/migrate.py`가 검토된 실행 순서와 SHA-256 체크섬을 기준으로 PostgreSQL 스키마를 관리한다. 신규 DB는 `init`을 사용한다. 관리 이력이 없는 기존 DB는 실제 적용 증빙과 스키마 표식을 대조해 `baseline`을 기록한 뒤 `upgrade`를 실행한다. 관리 이력이 있는 DB에는 `upgrade`로 미적용 마이그레이션을 적용한다.

## 영향

- 기존 DB를 채택하려면 과거 SQL 적용 증빙이 필요하다. `baseline`은 이력만 기록하고, 스키마 변경은 이후 `upgrade`에서 적용한다.
- 스키마 변경과 해당 적용 이력을 같은 트랜잭션으로 관리한다. 이미 적용한 SQL의 수정본은 체크섬 검사에서 거부되므로 후속 변경은 새 마이그레이션으로 추가한다.
- 초기 콘텐츠 seed와 RUNNING 회차에 대한 012 적용은 각 운영 절차에서 관리한다.
