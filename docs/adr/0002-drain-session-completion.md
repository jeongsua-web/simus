# ADR 0002 — 회차 종료에 DRAIN 정책을 사용한다

| 항목 | 내용 |
| --- | --- |
| 상태 | 채택 |
| 기록일 | 2026-11-18 |

## 배경

선택 한 건은 선택 원장과 도시·지역·개인 점수를 함께 갱신한다. 사용자 제출과 자동·수동 종료가 동시에 들어와도 확정 결과는 같은 시점의 원장과 점수 상태를 반영해야 한다.

## 결정

선택 처리와 종료가 같은 회차 행을 잠근다. 종료 작업은 이미 잠금을 획득한 선택 트랜잭션의 커밋 또는 롤백이 끝나기를 기다린다. 그 뒤 회차를 `CLOSING`으로 전환하고, 별도 트랜잭션에서 결과 저장과 `FINALIZED` 전환을 함께 완료한다. 이미 저장된 선택을 같은 요청 키와 내용으로 재시도하면 기존 결과를 반환한다.

## 영향

- 결과 확정 시각은 진행 중인 선택 처리와 종료 작업에 따라 접수 마감 시각보다 늦어질 수 있다. 중간에 멈춘 `CLOSING` 회차는 종료 조정 작업으로 복구할 수 있다.
- 전시 제품 정책은 종료 시각에 신규 입장과 선택 접수를 닫는다. 현재 저장소의 선택 API는 `scheduled_end_at - admission_buffer`에 접수를 닫고, DB 스키마는 양수 버퍼를 요구한다. 전시 정책을 적용하려면 선택 마감 조건과 스키마를 맞춰야 한다.
