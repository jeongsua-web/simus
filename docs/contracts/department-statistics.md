# 4A 회차별 학과 통계

2026-10-01 구현. 3C의 회차별 학과를 선택 원장 및 확정 결과와 연결한다. DB 마이그레이션은 추가하지 않는다.

## 공개 계약

`GET /api/sessions/{id}/department-statistics`는 공개·읽기 전용이며 `Cache-Control: no-store`를 사용한다. 존재하지 않는 회차는 404다. `/statistics/{id}` 화면과 개인 결과 화면의 `학과별 통계` 링크에서 조회할 수 있다.

- 45개 학과/구분을 목록 순서로 반환한다. `participant_count`는 해당 회차 가입자 수, `response_count`는 유효한 선택 원장 건수다. 재전송과 거부된 선택은 원장에 없으므로 중복 집계하지 않는다.
- 각 상황의 `respondent_count`는 그 학과에서 그 상황에 응답한 사람 수다. 선택지의 `ratio`는 **선택 건수 / 해당 상황 응답자 수**이며 0~1 숫자다. 응답자가 0명이면 화면에 `응답 없음`을 표시한다.
- 상황 응답자가 5명 미만이면 `suppressed: true`, `choices: null`이다. 참여자 수가 5명이어도 그 상황에 4명만 응답했다면 상세는 감춘다.
- `alignment`는 회차가 `FINALIZED`인 경우에만 반환한다. 그 전에는 `null`이며 개인 성향 분포를 계산하거나 응답에 넣지 않는다.
- 확정 후 성향 분모는 유효한 선택을 한 참여자 수다. `respondent_count`가 5명 미만이면 `distribution: null`이다. `no_response_count`는 가입자에서 유효 응답자를 뺀 수로 별도 표시한다. 0응답 결과 정책이 EXCLUDE인 기존 회차도 이 수를 볼 수 있다.
- 개인 ID, 점수, NPC ID, 응답 시각은 반환하지 않는다. 통계는 전시 참여자의 선택 경향이며 학과 구성원 전체의 성향으로 해석하지 않는다는 문구를 화면에 표시한다.

## 검증

`web`의 lint/build와 격리 PostgreSQL 통합 검사 통과. 4명 응답에서 상세 숨김, 5명 응답에서 4:1 비율, 종료 전 성향 비공개, 종료 후 분포 및 타 학과 1명 미응답 집계를 확인했다. 실제 휴대폰 화면 검증과 운영 DB 확인은 아직 별도다.
