# 2026-10-23 로컬 디스크 정리

사용자 승인에 따라 재생성 가능한 캐시와 로그만 삭제했다.
삭제 전 실행 중인 Unity Editor 및 Next.js 서버가 없음을 확인했다.

| 삭제 경로 | 삭제 전 디스크 점유량 (KiB) | 복원 방법 |
| --- | ---: | --- |
| `unity/Library/` | 2,099,288 | Unity 프로젝트를 열면 재생성. 재가져오기 및 빌드 시간이 필요함 |
| `web/.next/` | 991,572 | 웹 개발 서버 실행 또는 웹 빌드 시 재생성 |
| `unity/Logs/` | 5,888 | 향후 Unity 실행 로그 생성. 과거 로그는 복원하지 않음 |

삭제 대상 점유량 합계는 3,096,748 KiB(약 2.95 GiB)였다.
작업 후 프로젝트 점유량은 약 3.93 GiB, 디스크 가용 공간은 약 3.2 GiB였다.
가용 공간 수치는 파일시스템 및 다른 프로세스의 활동에 따라 달라질 수 있다.

원본 에셋, 소스 코드, `node_modules`, Unity 빌드 및 배포 백업, Git 이력은 유지했다.
세 삭제 경로는 Git 추적 대상이 아니므로 커밋에는 이 작업 기록만 포함한다.
기존 미커밋 작업 변경은 포함하지 않는다.

검증:

- `python3 scripts/assets/catalog.py`: 5,340개 파일, 오류 0개.
- `python3 scripts/assets/catalog.py --check`: 오류 0개.
- 에셋 목록은 갱신했으나 기존 미커밋 변경이 포함되어 있어 이번 커밋에서는 제외했다.
- 캐시 재생성을 피하기 위해 Unity 실행 및 웹 재빌드는 수행하지 않았다.
