# SIM:US 도시 스탯별 시각 변화와 제작 체크리스트

플레이어들의 선택에 따라 도시 스탯이 변하고, 그 변화가 도시 외형에 실시간으로 반영되도록 한다. 2026년 10월 20일 전시에서는 필수 에셋과 시각 효과를 우선 구현한다.

전시용 맵은 새로 제작하며, 재사용 가능한 개별 건물·소품 에셋을 활용한다. 기존 `Neighborhood.fbx`·`neighborhood.glb`의 좌표·동선·상황 배치는 재사용하지 않는다. 새 맵의 구역과 배치 좌표는 확정 후 연결한다.

관련 기준: [새 맵·Blender 자산 인계](../content/new-map-handoff-5a.md), [에셋 관리 규칙](../../assets/ASSET_RULES.md), [에셋 카탈로그](../../assets/catalog/README.md). 아래 체크박스는 작업 진행용이며 최종 자산 승인은 `assets/manifest.csv`에서 관리한다. 제안 목록은 제작 또는 승인 완료를 뜻하지 않는다.

## 1. 행복도

시민의 생활 만족도는 NPC 행동과 도시 장식으로 표현한다.

| 대상 | 행복도 높음 | 행복도 낮음 |
|---|---|---|
| NPC | 웃기, 대화하기 | 고개 숙이기, 한숨 |
| 벤치 | 시민들이 앉아 있음 | 텅 빈 벤치 |
| 거리 | 꽃 화분, 풍선 | 장식 없음 |
| 상점 | 영업 중, 밝은 간판 | 폐업 안내문 |
| 광장 | 축제 장식, 현수막 | 텅 빈 광장 |
| 주택 | 밝은 창문, 화분 | 어두운 창문 |
| 공원 | 피크닉 소품 | 방치된 소품 |

NPC 감정 아이콘(웃음·슬픔·분노)과 행동 애니메이션 확장은 전시 이후 작업으로 둔다.

## 2. 치안

도시의 안전과 질서는 파손 흔적과 사건 현장의 수량 및 상태로 표현한다.

| 대상 | 치안 높음 | 치안 낮음 |
|---|---|---|
| 경찰차 | 정상 순찰 | 출동 차량 증가 |
| 경찰 NPC | 순찰 | 사건 현장 대응 |
| 자동차 | 정상 주차 | 파손 차량 |
| 건물 | 정상 상태 | 깨진 유리창 |
| 골목 | 깨끗한 벽 | 낙서 |
| 도로 | 정상 통행 | 사고 현장 |
| 공공시설 | 정상 운영 | 출입 통제 |

경찰차나 CCTV의 수량만으로 치안 상태를 표현하지 않는다. 경찰차는 순찰과 출동 상태를 구분한다. 도로 사고 표지판은 사건 현장 연출 확장 후보로 둔다.

## 3. 청결도

눈에 보이는 쓰레기와 도시 관리 상태를 표현한다. 쓰레기 에셋을 재사용하고 스탯에 따라 활성 수량을 조절한다.

| 대상 | 청결도 높음 | 청결도 낮음 |
|---|---|---|
| 도로 | 깨끗한 도로 | 쓰레기 증가 |
| 인도 | 깨끗한 보도 | 얼룩, 오물 |
| 쓰레기통 | 정상 상태 | 쓰레기 넘침 |
| 공원 | 정돈된 잔디 | 쓰레기 방치 |
| 건물 외벽 | 깨끗한 외벽 | 얼룩 |
| 하천 | 쓰레기 없음 | 부유 쓰레기 |
| 골목 | 깨끗한 골목 | 쓰레기봉투 적치 |

쓰레기 세트는 종이, 페트병, 캔, 비닐봉지 등으로 구성한다. 낙엽 더미는 추가 후보로 둔다.

## 4. 오염도

대기·수질·토양의 환경오염 상태를 표현한다. 청결도의 쓰레기 표현과 구분하고 Unity 환경 효과를 중심으로 구현한다.

| 대상 | 오염도 낮음 | 오염도 높음 |
|---|---|---|
| 하늘 | 맑은 하늘 | 스모그 |
| 나무 | 푸른 나무 | 시든 나무 |
| 강 | 맑은 물 | 탁한 물 |
| 공장 | 정상 배출 | 검은 연기 |
| 도로 | 맑은 공기 | 매연 |
| 공원 | 싱그러운 식물 | 죽은 식물 |
| 도시 전체 | 선명한 시야 | 뿌연 시야 |

| Unity 기능 | 적용 대상 | 구현 방법 |
|---|---|---|
| Lighting | 도시 전체 | 조명 색상과 밝기 조절 |
| Fog | 도시 전체 | 오염도가 높아질수록 안개 농도 증가 |
| Particle System | 공장, 도로 | 검은 연기와 자동차 매연 발생량 조절 |
| Material | 강, 하천 | 수면 색상과 투명도 변경 |
| Material | 나무, 잔디 | 식생 색상 변경 |

시든 나무와 죽은 물고기 등은 보조 표현으로 활용한다. 공장 굴뚝은 새 맵에 공장이 포함될 경우 제작 필요성을 확인한다.

## 6. 스탯별 5단계 도시 변화

행복도·치안·청결도는 높을수록 좋고, 오염도는 낮을수록 좋다. 아래 범위는 정수 스탯 기준이다.

| 스탯 범위 | 행복도 | 치안 | 청결도 | 오염도 |
|---|---|---|---|---|
| 0~20 | 침체 | 매우 위험 | 매우 더러움 | 매우 깨끗한 환경 |
| 21~40 | 우울 | 위험 | 더러움 | 양호 |
| 41~60 | 보통 | 보통 | 보통 | 보통 |
| 61~80 | 활기 | 안전 | 깨끗함 | 오염 심화 |
| 81~100 | 축제 분위기 | 매우 안전 | 매우 깨끗함 | 심각한 오염 |

단계가 변할 때 모든 에셋을 교체하지 않는다. 청결도는 다음과 같이 배치 가능한 쓰레기 슬롯의 활성 비율로 표현할 수 있다.

| 청결도 | 쓰레기 배치량 | 바닥 얼룩 | 넘치는 쓰레기통 |
|---|---|---|---|
| 81~100 | 0% | 없음 | 없음 |
| 61~80 | 25% | 없음 | 없음 |
| 41~60 | 50% | 일부 | 없음 |
| 21~40 | 75% | 증가 | 일부 |
| 0~20 | 100% | 다수 | 다수 |

실제 슬롯 수와 위치는 새 맵 배치가 확정된 뒤 정한다.

## 7. 독립 적용과 구역별 변화

각 스탯은 독립적으로 도시 외형에 영향을 준다. 행복도 90, 치안 30, 청결도 80, 오염도 70이라면 축제 현수막과 꽃 화분, 파손 차량, 스모그가 동시에 나타날 수 있다. 하나의 종합 상태로 다른 스탯의 효과를 덮어쓰지 않는다.

도시 전체에 동일한 파손을 적용하지 않고 구역별로 표현을 나눈다. 다음은 설계 예시이며 확정된 새 맵 구역이나 좌표가 아니다.

| 구역 예시 | 치안 하락 시 변화 |
|---|---|
| 주택가 | 벽 낙서 증가 |
| 상업지구 | 파손 차량 등장 |
| 공원 | 경찰 통제선 등장 |

## 8. 개발 우선순위

1차 구현은 10월 20일 전시를 위한 필수 17종과 스탯 연동이다. 행복도는 장식과 상점 상태, 치안은 차량과 파손 흔적, 청결도는 쓰레기와 얼룩, 오염도는 식생과 환경 효과를 우선 연결한다.

2차 구현은 전시 이후 권장·선택 에셋, NPC 감정 및 행동 애니메이션, 경찰 NPC와 사건 현장, 공원·광장 장식 다양화, 하천 부유 쓰레기, 식생 변화, 구역별 환경 변화 고도화다.

## 9. 최종 구현 방향

1. 에셋 활성화·비활성화: 스탯에 따라 오브젝트를 표시하거나 숨긴다.
2. 배치 수량 조절: 쓰레기·장식·파손 흔적의 활성 수량을 변경한다.
3. Unity 환경 효과 변경: Lighting, Fog, Particle System, Material을 조합한다.

행복도·치안·청결도는 에셋 배치와 상태 변화, 오염도는 환경 효과를 중심으로 구현한다. 개별 에셋을 재사용하면서 참가자들의 선택으로 서로 다른 도시 외형이 만들어지도록 한다.
