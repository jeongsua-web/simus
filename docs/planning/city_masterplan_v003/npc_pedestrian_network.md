# v003 NPC 보행망 개정안

보도·보행로를 따라 이동하고, 차도 양쪽 보도를 잇는 구간은 저장된 v003 Unity 씬에서 횡단보도 오브젝트를 찾을 수 있는 곳에 둔다. [경로 데이터](npc_pedestrian_network.json)는 기존 [마스터플랜 경로](routes.json)의 노드·구간 ID를 사용한다. 구간별로 통행 가능 여부, 횡단보도 ID, 차단 이유와 대체 경로를 기록했다.

## 이동 규칙

- **보행 구간**은 기존 보도, 골목, 광장, 산책로, 출입구 경로 중 NPC 몸체가 계획 차도와 겹치지 않는 구간을 사용한다. 골목에서 차도에 닿으면 같은 쪽 보도를 따라 경로에 포함된 횡단 지점으로 이동한다.
- **횡단 구간**은 건너는 도로의 횡단보도 안에 차도와 겹치는 모든 부분이 들어가야 한다. 양 끝은 차도 밖에 두고, 진입 지점에서 반대편까지 한 구간으로 연결한다. 교차로에서 두 도로에 동시에 걸치는 사선 연결이나 차도 한가운데서 끝나는 구간은 차단한다.
- **정지 및 목적지**는 차도 밖 노드에 둔다. 횡단 중 새 목적지가 생기면 반대편 보도에 도착한 뒤 다시 경로를 계산한다. 신호가 있는 횡단보도에서는 보도 쪽 진입점에서 신호를 기다리고, 보행 우선 구간은 차량 양보가 확인되면 진입한다.
- **길이 끊긴 경우** NPC는 마지막 보행 지점에서 대기한다. 목적지 좌표를 직선으로 연결해 차도에 진입시키는 처리는 금지한다. 자동 우회는 연결된 구간만 사용하며, 설계 비교용 비용은 걷기 1.4m/s와 신호 제어 횡단마다 예상 대기 12초로 계산한다. 실제 신호 주기와 대기 시간은 런타임 제어에서 결정한다.

## 경로 변경

| 항목 | 설계 검사 결과 |
| --- | --- |
| 일반 보행 | 479구간 |
| 지정 횡단 | 39구간, 횡단보도 39곳 |
| 차단 | 13구간 |
| 정문 연결망 | 483개 중 476개 노드 연결, 7개 고립 |
| 상황 접근 우회 | 07·11·14·16·18·27은 원래 목적지 노드까지 대체 경로 계산 |
| 상황 보행 지점 보완 | 03·26은 R11·R13 교차부에서 대기점을 보도로 옮겨야 한다. 28은 R06·R07 합류부 바깥에 접근·정지 지점이 필요하다. |

골목 지름길 W0235는 CW24와 일부 겹치더라도 지정 횡단 연결을 사용하도록 차단했다. 기존 보행 구간 W0318은 R06의 CW18 횡단 띠 안에서 양쪽 보도를 연결해 횡단 구간으로 지정했다. CW19와 CW39는 씬에 횡단보도 오브젝트가 있으나, 각각 R06·R07과 R11·R13이 겹치는 곳에서 보도까지 온전히 이어지는 구간을 확보하지 못했다. CW41은 대응하는 횡단보도 오브젝트를 저장 씬에서 찾을 수 없었다.

## 검사 범위와 적용 기준

- 생성기는 계획 도로 중심선과 폭으로 X/Z 차도 영역을 만들고, 각 경로의 연속 선분을 검사한다. 차도 영역은 NPC 반경 0.28m만큼 넓히고, 횡단 띠는 양옆에서 같은 반경만큼 좁힌다. Unity 씬의 횡단보도 오브젝트 이름을 대조한다. 보도·차도 메시와 횡단보도 실측, 턱 낮춤, 경사, 장애물, 차량 양보와 신호 동작은 Unity에서 확인해야 한다.
- 같은 기준으로 저장된 웹 경로를 검사했다. 운영 v003의 `EXHIBITION_30` 접근·복귀 경로에는 계획 차도와 겹치는 구간이 없었다. 개발용 NavMesh 내보내기 경로는 27개 중 17개에서 지정 횡단보도 범위 밖 차도 겹침이 확인됐다. 경로별 도로 ID는 데이터의 `saved_event_path_audit`에 기록했다.
- Unity에 적용하기 전에 횡단보도 양끝과 보도 접속부를 실측하고, 접근·왕복·차단 시 대기를 NPC로 재생한다. 차도 진입 프레임부터 이탈 프레임까지 허용된 횡단 띠를 벗어나지 않는지 확인한다. 웹 회차 위치 이벤트는 기존에 검증된 `EXHIBITION_30`을 사용한다. 이 설계 데이터는 게임에서 아직 사용되지 않는다.

저장소 루트에서 다음 명령으로 경로 데이터를 재생성하고 검증한다.

```sh
python3 scripts/verification/v003_pedestrian_network.py
python3 scripts/verification/v003_pedestrian_network.py --check
```
