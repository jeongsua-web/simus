# CityRebuild_v002 — Phase 4 하천 설계

2026-10-15 사용자 요청에 따라 Phase 4 공원·녹지 범위에 하천을 추가한다. 설계 결과를 먼저 보고한 뒤 증분 Unity 구현을 진행한다. 이 문서의 좌표는 현재 v002 배치에 대한 작업 설계이며 전시 `map_version`, 회차 데이터, 30개 상황 좌표의 확정이 아니다.

## 위치와 형상

동쪽 공원 내부에 길이 약 170.67m의 완만한 곡선 하천을 넣는다. 중심선 제어점은 Unity X/Z 미터 기준 `(127,-12) → (122,15) → (118,45) → (118,75) → (120,104) → (120,125) → (133,155)`이며, Catmull–Rom 곡선을 로우폴리 메시로 샘플링한다. 북쪽 수원과 남쪽 완충 수역에서 둥근 하상·사면으로 닫아 수면이 수직으로 잘려 보이지 않게 한다.

수면 폭은 **10m 고정**이다. 8~12m 범위를 검토했지만 12m는 인접 PKE01 보행면을 약 0.22m 침범한다. 폭 변경은 지형·보행망·교량을 함께 재검증해야 한다. 양안 2.4m 산책로와 둔치를 포함한 전체 작업 폭은 24m다.

| 구성 | 중심선에서의 거리 | Unity Y |
|---|---:|---:|
| 하상 바닥 | 0~3.0m | −2.00m |
| 수면 가장자리 | 5.0m | −1.20m |
| 사면 상단 및 둔치 | 6.5~8.3m | −0.45m |
| 양안 산책로 | 8.8~11.2m | −0.43m |
| 주변 지면 접속 | 12.0m | −0.02m |
| 기존 보행로와 보행교 상면 | 교차 지점 | +0.14m |

`CityGround`와 `EastPark_Lawn`의 렌더 메시와 Collider를 모두 절개한다. 내려간 하상·수면·둔치가 서로 독립된 표면이어야 하며 기존 지면 위에 물 색 평면을 얹는 구현은 허용하지 않는다. 기존 보행로와 낮은 산책로의 높이 차 0.57m는 약 12m 경사로를 기준으로 연결한다.

## 기존 배치와 충돌 검토

| 대상 | 전체 24m 폭 기준 최소 여유 |
|---|---:|
| 도로와 보도 외곽 | 21.381m |
| 건물 배치 외곽 | 22.756m |
| 공원 경계 | 2.201m |
| PM1 / PM2 모듈 | 0.479m / 3.560m |
| PZ01 / PZ02 휴식 공간 | 1.352m / 3.892m |

처음 검토한 북측 중심선 X=126m는 PM2/PZ02를 침범해 X=120m 쪽으로 조정했다. 현 값은 설계 평면의 유한 폭 검사이며 최종 Unity Collider, 난간 진입부, 실제 NPC 궤적 검사를 대신하지 않는다. PM1과의 여유가 작으므로 장식·돌·난간을 작업 폭 밖으로 임의 확장하지 않는다. 건물 69동과 기존 도로 배치는 유지하며, 필요한 경우 하천 영향권의 추가 식생만 최소 조정한다.

## 보행교와 NPC

수면을 가로지르는 기존 보행 간선은 PKE02와 PKE07 두 곳이다. 북측 약 28.70m, 남측 약 32.10m의 보행교를 같은 방향에 배치하고 유효 폭은 3m로 한다. 길이는 하천 전체 단면을 비스듬히 건너는 거리와 단부 여유를 반영한다. 길이가 늘어난 교량 안쪽으로 기존 PK02/PK08 접근로가 연결되므로 해당 위치의 난간에 실제 진입구를 둔다.

PKE01·PKE08·PK_LOOP_S1은 물 밖이지만 낮아지는 둔치 영향권과 만난다. 지지 지면·접근부와 경사로를 함께 조립해야 하며 공중에 떠 있는 기존 산책로를 남기지 않는다. 양안 산책로와 교량을 현재 씬의 보행 그래프에 추가하고, 기존 JSON/CSV는 원본 설계로 유지한다. 물과 하상은 보행 지원 Collider 및 경로에서 제외한다. 실제 NPC 이동 중 수면 침범, 미지지 지면, 난간 통과 여부를 별도 검증한다.

## 에셋과 수질 표현

독립 하천·교량 모델은 기존 라이브러리에서 발견되지 않았다. 나무와 벤치는 재사용하고, 하천 절개·수면·둔치는 Unity 생성 메시로 구성한다. Blender 신규 제작은 보행교 kit 한 묶음(두 길이의 deck와 별도 난간 모듈)으로 제한한다. 기존 난간은 반복 이음새와 기둥 중첩 문제가 있어 새 교량의 모듈 난간을 사용한다.

수면은 씬 전용 Standard 머티리얼과 `CityV002RiverWater`를 사용한다. 도시 전체 오염도 0~100에 따라 청록색에서 탁한 올리브색으로 색과 매끄러움을 보간한다. `MaterialPropertyBlock`을 사용해 공유 원본 머티리얼을 변경하지 않는다. 기존 도시 상태의 aggregate를 연결하며 미확정 지역 코드는 추정하지 않는다. 서버가 없는 경우 Inspector의 오염도 또는 지정한 기존 `CityStateAssets`로 확인할 수 있다.

## 구현·검증 기록

구현 전 현재 작업 씬 백업과 보호 파일 해시는 [기준선](../../verification/city-rebuild-v002-river-baseline.json)에 기록했다. 현재 씬에는 Phase 4 공원·녹지가 이미 있으므로 Phase 1~3 또는 Phase 4 전체 재생성을 실행하지 않는다. 신규 하천 생성기만 증분 적용한다. 최종 적용, 실행 캡처, NPC, 수질 테스트 결과는 후속 검증 보고서에서 별도로 판정한다.
