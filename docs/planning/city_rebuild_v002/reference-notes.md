# 한국 대학가 설계 참고 근거

확인일: 2026-10-14. 실측은 기존 Blender 조사 결과를 사용하고, 외부 자료는 공간 구성과 도로 위계의 참고로만 사용한다. 실제 대학의 좌표·축척·건물은 복제하지 않는다.

- [연세대학교 신촌캠퍼스 소개](https://yonsei.ac.kr/sc/662/subview.do): 신촌에서 캠퍼스 보행축으로 이어지는 진입과, 보행축 양쪽에 여러 교육·생활 시설이 배치된 구조를 참고했다. 이 계획에 적용한 해석은 정문 주변 상업 가로와 캠퍼스 내부 보행축을 이어 주고, 학교를 균일한 도시 블록으로 분해하지 않는 것이다.
- [연세대학교 캠퍼스 도보길찾기 도움말](https://campusmap.yonsei.ac.kr/help/): 여러 출입문을 구분하는 대학 보행 접근의 사례를 참고했다. 이 계획의 정문·후문은 기존 메시의 문 확정 사실과 구분되는 설계 접근점이며, 현장/메시 시각 검증을 거쳐야 한다.
- [국가법령정보센터 도로구조규칙 제10조](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1030368339): 도로 기능에 따른 차로 수와 폭을 참고했다. 도시지역 저속 일반 차로 3m 기준을 공간 규모 참고로 사용한다. 게임용 차도·보도·공유골목은 실제 도로 인허가 설계가 아니며, 이 문서로 법규 적합성을 주장하지 않는다.

학교 부지의 원형 보존, 혼합 주거의 간격 변화, 정문 상권의 작은 필지, 비정형 공원 및 국지 연결망은 기존 에셋 실측에 맞춘 창작 설계다. 외부 자료가 이 배치 좌표나 모든 출입구의 정확성을 증명하지 않는다.
