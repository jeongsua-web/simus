# SIM:US 시제품 작업 상태

2026-09-24, 4~8단계 개발 사본 기준. 기존 2단계 Unity 미리보기와 3단계 PostgreSQL
서버 구현을 기반으로 한다. `sources/`, 기존 `Neighborhood.unity`, 서버/SQL은 보존했다.
공통 API: `contracts/API.md`. 실행: `실행안내_4-8단계.md`.

|---|---|

| 4 모바일 | 참여·선택·복원·마감 대기·개인/과거 결과 화면 구현 완료. 테스트 PostgreSQL API 실제 연결 검증 완료. 390px 브라우저 검증 완료. 실기기·QR 미완료 |
| 5 Unity 상태 | 별도 장면/HUD/공개 API 폴링·오류·회차/버전 보호 구현 완료. 테스트 PostgreSQL과 실제 Unity Play 모드 연결 검증 완료. 로컬 선택 후 새 버전 감지 0.207초. 전시 LAN 미검증 |

| 8 최종 도시·캐릭터 | 최종 도시 수치와 본인 성향은 조회 가능. 최종 이미지·캐릭터 결과 자산 미완료 |
| 8 알림 | 열린 모바일 화면의 결과 공개 확인은 구현. 외부 채널·동의·발송 미완료 |

실제 서버 상태와 테스트 데이터를 화면 배너와 보고서에서 구분한다. 클라이언트는
API 실패를 모의 성공으로 전환하지 않는다. 모의 NPC 실험은 실제 서버와 별개다.
학과 목록·알림 채널과 수신 동의 방식·모바일 본인 NPC 제공 방식 및 지원 기기·전시 일정은
사용자 결정이 필요하다. 서버 변경 제안은 `contracts/API.md`를 서버 담당자에게 전달한다.
