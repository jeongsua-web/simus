# 4~8단계 통합 검증

2026-09-24. 전용 임시 PostgreSQL 18 클러스터와 localhost API/프록시를 사용했다.
운영 DB·실제 전시 서버·실제 휴대폰은 사용하지 않았다.

| 범위 | 증거 | 결과 |
|---|---|---|
| 기존 서버 회귀 | `postgres-test.log` | 12/12 통과. 2인 개인 분리/도시 합산, 중복·동시 요청, 마감 정각, 권한, 수동/자동 종료, 두 회차 보존 포함 |
| 새 화면 경유 실제 API | `smoke.py` | 별도 쿠키 2명 A/B 선택, 도시 50.3/50/50.5/0, 요청 재전송, 무권한 종료 거부, 종료 후 개인 분리·불변, 새 회차 초기화·과거 결과 보존 통과 |
| 모바일 Chrome | 390px DevTools Responsive 뷰포트 | 참여·상황·선택·제출·이미 응답·새로고침 복원·수동 종료 후 본인 결과 공개를 브라우저에서 확인. 가로 잘림 없이 큰 터치 버튼. 실제 휴대폰 확인은 별도 |

Chrome 최초 모바일 화면에서 중첩 template literal 닫힘 오류를 발견해 수정했다.
프록시가 실제 API 연결 실패 시 502와 명시적 오류를 돌려주고 모의 데이터로
전환하지 않는 것도 확인했다. 미인증 `/api/me` 반복 조회는 한 회차당 최초 한 번으로
줄였다. 원본 PostgreSQL 서버·SQL 파일은 변경하지 않았다.

미검증: 실제 휴대폰 2대, LAN/QR, 관리자 키 입력 UI, 전시용 Unity 빌드,
알림 채널, 학과 통계, 실제 참여자 NPC 공유 경로, 최종 도시/캐릭터 이미지.
자동 종료 경계·권한·반복 종료는 기존 서버의 전용 PostgreSQL 통합 검사에서
검증한 범위다. 부하 중 극단적인 물리 커밋 지연은 기존 서버 문서의 한계로 남는다.
