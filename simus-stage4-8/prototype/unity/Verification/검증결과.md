# Unity 맵 검증 결과

검증일: 2026-09-22. Unity 6000.3.24f1, macOS ARM64.

- Blender 원본 보존: 내보내기 전후 SHA-256 동일. 상세 값은 `../SIMUSPrototype/Assets/Art/NeighborhoodExportReport.json` 참조.
- Unity 가져오기: 성공. 725개 메시 렌더러, 32개 독립 재질 매핑.
- 맵 경계: X 200.000m / Y 18.250m / Z 200.000m.
- 스크립트 및 셰이더: 컴파일 성공. 최종 장면 생성·렌더 로그에서 컴파일 오류·셰이더 오류·예외 없음.
- 실제 렌더: `Unity_Overview.png`, `Unity_Plan.png`. 조감도에 전체 맵이 들어옴. 원본과 학습 구역·공원·상업 구역·연못 배치 및 글자 방향 일치.
- 실행: Play 모드 100회 편집기 갱신 후 배치도 하향 카메라와 조감도 복귀 확인, 종료 코드 0.
- 편집기 부가 기능: 위 Play 검사 중 Unity 자체 검색 인덱스 초기화에서 `ArgumentOutOfRangeException` 1회 기록. 호출 경로는 `UnityEditor.Search.SearchDatabase`이며, 맵 스크립트 검사는 이후 정상 완료됨.
- 수정한 표시 문제: 대소문자만 다른 재질 파일 이름 충돌, 뒤쪽 면 조명, 맵 가장자리 잘림, 얇은 표면의 그림자 줄무늬.
- 사용자 화면 확인: 편집기 GUI를 열었으나 최초 Unity Editor Software Terms 동의 창에서 대기 중. 약관 동의는 수행하지 않았으며, GUI에서 사용자가 직접 누르는 조작 검증은 남아 있음. 위 Play 검사와 렌더는 Unity 배치 실행 결과임.

서버·모바일 연결, NPC 이동 및 실제 전시 기기의 성능 측정은 아직 수행하지 않았습니다.

  낡은 버전/이전 회차 차단, NPC 이동, FINALIZED 후 동결 확인(`stage-play.txt`).

  실기기 프레임률·운영 최종 시각 조건은 미검증.
