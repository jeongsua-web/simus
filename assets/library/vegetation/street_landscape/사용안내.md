# SIM:US — 한국 가로수와 거리 소품 10

기존 도시 에셋과 어울리는 단순한 형태의 3D 모델입니다. 가로수 5종에 은행나무 단풍 변형을 더하고, 화단·벤치·쓰레기통까지 총 9개 독립형 에셋을 제공합니다.

| 파일 이름 부분 | 에셋 |
|---|---|
| Ginkgo_Green | 은행나무 녹색 수관 |
| Ginkgo_Autumn | 같은 은행나무의 노란 단풍 변형 |
| Zelkova | 넓게 퍼지는 수관의 느티나무 |
| Cherry | 분홍 꽃이 핀 왕벚나무 |
| FringeTree | 흰 꽃이 핀 이팝나무 |
| Metasequoia | 층을 이루는 원뿔형 메타세쿼이아 |
| Flowerbed | 콘크리트 화단과 여러 색 꽃 |
| Bench | 목재 좌판·등받이, 금속 다리·팔걸이 벤치 |
| TrashBin | 전면 투입구와 도어가 있는 공용 쓰레기통 |

수종 특징을 단순화한 게임용 표현입니다. 개화·단풍 상태는 에셋별로 고정되어 있으며 자동 계절 전환은 포함하지 않습니다.

## 파일

- 각 모델별 `SIMUS_이름.glb`, `.fbx`: 원점에 배치된 개별 모델
- `SIMUS_Street_Landscape_Collection.blend`: 전체 편집 원본
- `SIMUS_Trees_Preview.png`: 가로수 6가지 외형 미리보기
- `SIMUS_Street_Furniture_Preview.png`: 화단·벤치·쓰레기통 미리보기
- `validation.json`: 모델별 실제 크기와 메시 개수

외부 텍스처 없이 메시와 색상 재질로 표현했습니다. 반복되는 작은 조각은 재질별로 합쳐 오브젝트 수를 줄였습니다. 은행나무 녹색·단풍 모델은 같은 형태이므로 서로 교체할 수 있습니다.

## 크기와 배치

각 모델의 원점은 지면 중앙입니다. 가로수 높이는 약 5~8m, 화단은 2.8 × 0.9m, 벤치는 폭 1.85m, 쓰레기통은 약 0.51 × 0.51 × 0.99m입니다. 정확한 외곽 범위는 validation.json에 기록했습니다.

기존 보도나 건물 부지 위에 놓을 때 원점 높이를 해당 보도 상단인 Z=0.158m에 맞추세요. 가로수는 나무 형태만 포함하므로 지형의 식재 공간이나 별도 화단에 배치합니다. 원본의 좁은 1m 보도에는 나무·벤치·화단이 보행 공간을 차지할 수 있으므로 넓은 보도나 부지 옆 공간을 확보하세요. 가지와 수관이 차도·신호등을 가리지 않게 배치합니다.

벤치와 쓰레기통의 정면은 Blender -Y입니다. 모음 Blender 파일에서는 보기 좋게 위치를 펼쳐놓았으므로 각 루트 위치를 초기화한 뒤 배치하세요. 개별 GLB/FBX는 이미 원점에 맞춰져 있습니다.

Unity에서는 FBX를 배율 1, 1 unit=1m로 가져오고 수평면 XZ 방향을 확인하세요. GLB에는 별도 glTF 가져오기 기능이 필요합니다. Unity 내부 가져오기는 검증하지 않았습니다. 나무 흔들림·꽃 애니메이션·착석·쓰레기 투입 기능, 충돌체·LOD는 별도 구현 대상입니다.

스튜디오 바닥·조명·카메라는 `Presentation`에 분리했으며 개별 GLB/FBX에는 포함하지 않았습니다. 기존 제작물은 수정하지 않았습니다.
