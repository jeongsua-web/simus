# SIM:US — 주차장 05

기존 도로·건물 부지와 같은 색상 계열의 30 × 24m 독립형 주차장입니다.

- 총 16면: 위아래 8면씩, 구획당 3 × 5m
- 중앙 양방향 통로 폭 6m, 서쪽(-X) 출입구 폭 6m
- 주차선·구획 번호·진행 화살표·중앙 점선
- 차량 멈춤턱·반사 표시·출입구 배수구
- 외곽 보행 공간과 경계석

게임용 배치 규격이며 실제 주차장 설계 기준 검증을 의미하지 않습니다. 차량·신호·차단기·가로등은 포함하지 않았습니다.

## 파일

- `SIMUS_Parking_Lot_16.blend`: 편집 원본
- `SIMUS_Parking_Lot_16.glb`: 3D 교환용
- `SIMUS_Parking_Lot_16.fbx`: Unity 기본 가져오기용
- `SIMUS_Parking_Lot_Preview.png`: 입체 미리보기
- `SIMUS_Parking_Lot_Plan.png`: 평면 미리보기

## 배치

원점은 주차장 중앙의 아스팔트 표면입니다. Blender에서 전체 범위는 X=-15~15m, Y=-12~12m입니다. 아스팔트 상단 Z=0, 보도 상단 Z=0.158m, 경계석 상단 Z=0.17m로 이전 에셋과 높이를 맞췄습니다.

출입구 중심은 (-15,0,0), 폭은 6m입니다. 도로에 연결할 때 기존 직선 도로의 보도·경계석을 출입구 구간에서 제거하거나 진입용 연결부를 만들어야 합니다. 기존 도로 옆에 붙이는 것만으로 차량 통로가 자동으로 열리지는 않습니다. 외곽 보행 공간은 건물 부지 보도와 같은 높이로 연결할 수 있습니다.

Unity에서는 FBX를 배율 1, 1 unit=1m로 가져옵니다. 수평면이 XZ로 변환되므로 축과 방향을 확인하세요. GLB에는 별도 glTF 가져오기 기능이 필요합니다. Unity 내부 가져오기는 이번 작업에서 검증하지 않았습니다. 충돌체·차량 경로·주차 로직은 별도 설정합니다.

Blender의 `Presentation` 컬렉션은 촬영용입니다. FBX/GLB에는 스튜디오 바닥·조명·카메라가 포함되지 않습니다. 기존 도로·건물 부지는 수정하지 않았습니다.
