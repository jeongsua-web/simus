# SIM:US — 기본 건물 부지 04

기존 도로 세트의 밝은 보도와 맞춘 30 × 24m 기본 부지입니다. 중앙에 24 × 16m 건물 배치면을 두고, 전면 5m·후면 3m·좌우 3m 보행 공간을 확보했습니다.

## 구성

- 건물 배치면, 외곽 보도 포장, 가장자리 띠, 정면 진입로 표시, 입구 앞 배수구
- 별도 편집 가능한 오브젝트와 재질
- 도로 표면 기준 Z=0, 부지 포장·건물 배치면 상단 Z=0.158m
- 부지 중심 원점, 정면 -Y 방향

## 제공 파일

- `SIMUS_Building_Plot_30x24.blend`: 편집 원본
- `SIMUS_Building_Plot_30x24.glb`: 3D 교환용
- `SIMUS_Building_Plot_30x24.fbx`: Unity 기본 가져오기용
- `SIMUS_Building_Plot_Preview.png`: 부지 단독 미리보기
- `SIMUS_Building_Plot_Plan.png`: 평면 미리보기
- `SIMUS_Building_Plot_Placement.png`: 기존 백화점 배치 예시

## 배치 방법

Blender에서 부지 루트를 (0,0,0)에 두었을 때 건물의 바닥 중앙 원점을 **(0,1,0.158)**에 놓습니다. 정면이 -Y인 건물은 별도 회전 없이 배치할 수 있습니다. 건물 크기에 따라 배치면과 입구 앞 배수구 위치를 조정하세요.

앞쪽에 기존 10m 직선 도로 3개를 붙이려면 각 도로 루트를 **(-10,-15.75,0), (0,-15.75,0), (10,-15.75,0)**에 놓고 Z축으로 90도 회전합니다. 이렇게 하면 도로의 보도 바깥 끝이 부지 앞쪽 경계 Y=-12와 맞닿습니다. 이는 계산한 배치 좌표이며 이번 미리보기에는 도로를 포함하지 않았습니다.

Unity에서는 FBX를 배율 1, 1 unit=1m로 사용하고 수평 XZ 평면으로 바뀌는 방향을 확인하세요. GLB에는 glTF 가져오기 기능이 필요합니다. Unity 내부 가져오기는 이번 단계에서 검증하지 않았습니다. 충돌체와 보행 경로는 별도 설정합니다.

기존 백화점은 배치 확인용 이미지에만 사용했습니다. 건물과 스튜디오 바닥·조명은 부지의 FBX/GLB에 들어 있지 않습니다. Blender의 `Presentation` 컬렉션은 미리보기용입니다. 주차장·차량 진입로는 후속 에셋이며 이번 부지에는 포함하지 않았습니다.
