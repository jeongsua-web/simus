# SIM:US — 편의점 11

청록색 간판과 코랄색 차양 띠를 사용한 단층 `SIM:US MART` 외관 에셋입니다.

- 본체 8 × 6m, 차양과 앞쪽 진입 공간 포함
- 한글·영문 간판, 24H 표시, 쇼윈도와 상품 포스터
- 닫힌 유리 출입문, 출입 매트, 측면 서비스 문, 옥상 설비
- 창문은 기존 건물과 맞춘 불투명 스타일 유리 재질

## 제공 파일

- `SIMUS_Convenience_Store.blend`: 편집 원본
- `SIMUS_Convenience_Store.glb`: 교환용 3D 모델
- `SIMUS_Convenience_Store.fbx`: Unity 기본 가져오기용
- `SIMUS_Convenience_Store_Preview.png`: 입체 미리보기
- `SIMUS_Convenience_Store_Front.png`: 정면 미리보기
- `validation.json`: 차양·진입 공간·설비를 포함한 실제 외곽 크기

## 배치 및 사용

원점은 본체 바닥 중앙이며 정면은 Blender -Y입니다. 기존 부지 위에 놓을 때 부지 표면 높이에 맞게 원점을 이동하세요. 자체 앞쪽 바닥은 정면으로 약 1.2m 돌출하므로 도로·보도와 겹치지 않게 여유를 두세요.

Unity에서 FBX를 배율 1, 1 unit=1m로 가져오고 수평 XZ 방향을 확인하세요. GLB는 별도 glTF 가져오기 기능이 필요합니다. Unity 내부 가져오기는 이번 작업에서 검증하지 않았습니다. `Presentation` 컬렉션은 촬영용이며 개별 GLB/FBX에서 제외했습니다.

매장 내부·입장 기능·문 열림·상품 구매 기능은 포함하지 않은 외관 에셋입니다. 글자는 메시로 변환되어 글꼴 없이 표시되며, 원문은 해당 오브젝트의 source_text 속성에 기록했습니다. 충돌체는 엔진에서 별도 설정합니다.
