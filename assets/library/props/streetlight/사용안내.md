# SIM:US — 가로등 06

도로·주차장에 배치하는 약 6m 높이의 단일 암 가로등입니다.

- 청회색 금속 기둥, 짧은 수평 암, 따뜻한 LED 발광부
- 0.38 × 0.38m 고정판, 앵커 볼트, 점검 덮개
- 원점: 고정판 바닥 중앙 / 암 방향: Blender +X
- 발광부와 기둥 재질을 분리해 색상·점등 상태 수정 가능

## 제공 파일

- `SIMUS_Streetlight_6m.blend`: 편집 원본 및 실제 스포트 조명
- `SIMUS_Streetlight_6m.glb`: 모델·발광 재질·KHR_lights_punctual 스포트 조명
- `SIMUS_Streetlight_6m.fbx`: 모델 및 재질 (실제 광원 제외)
- `SIMUS_Streetlight_Day.png`: 낮 미리보기
- `SIMUS_Streetlight_Night.png`: 기존 직선 도로에 배치한 야간 미리보기

## 배치

기존 직선 도로 원점이 (0,0,0)일 때 왼쪽 보도 위에는 가로등 원점을 **(-3.25,0,0.158)**에 놓습니다. 기본 +X 방향 암이 도로를 향합니다. 오른쪽 보도에서는 **(3.25,0,0.158)**에 배치하고 Z축으로 180도 회전합니다. 기둥 고정판은 기존 1m 보도 안에 들어갑니다.

Unity에서 FBX를 배율 1로 가져온 뒤 발광 재질과 Spot Light를 별도로 설정하세요. Blender 조명 위치는 (1.13,0,5.68), 아래쪽 방향, 각도 100도입니다. 엔진별 빛 세기가 달라 게임 화면에서 밝기를 조정해야 합니다. GLB의 광원 확장은 가져오기 도구의 지원 여부에 따라 적용됩니다. Unity 내부 가져오기는 이번 작업에서 검증하지 않았습니다.

Blender의 `Warm street light` 에너지를 0으로, `Warm LED diffuser`의 Emission Strength를 0으로 바꾸면 소등 상태가 됩니다. 야간 이미지에서는 보기 쉽게 광량을 950W로 조정했으며 원본과 GLB에는 600W로 저장했습니다. 자동 낮밤 전환이나 게임 조명 제어 코드는 포함하지 않습니다.

`Presentation` 컬렉션은 촬영용입니다. 도로는 야간 이미지에만 사용했으며 가로등 내보내기 파일에는 포함하지 않았습니다. 충돌체는 엔진에서 별도 설정합니다.
