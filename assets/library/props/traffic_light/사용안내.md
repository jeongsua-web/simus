# SIM:US — 차량용 신호등 07

기존 가로등과 같은 청회색 금속을 사용한 가로형 3색 신호등입니다. 기둥·수평 암·차광 덮개·고정 볼트·점검 덮개와 독립된 빨강/노랑/초록 렌즈로 구성됩니다.

- 높이 약 6.1m, 고정판 0.42 × 0.42m
- 원점: 고정판 바닥 중앙
- Blender 기준 신호 정면 -Y, 수평 암 -X
- 정면에서 왼쪽부터 빨강·노랑·초록
- 보행자 신호등·좌회전 화살표는 별도 제작 대상

## 파일

- `SIMUS_Traffic_Light.blend`: 편집 원본, 빨간불 기본 상태
- `SIMUS_Traffic_Light.fbx`: Unity 기본 가져오기용
- `SIMUS_Traffic_Light_Red.glb`: 빨간불
- `SIMUS_Traffic_Light_Amber.glb`: 노란불
- `SIMUS_Traffic_Light_Green.glb`: 초록불
- `SIMUS_Traffic_Light_Preview.png`: 전체 미리보기
- `SIMUS_Traffic_Light_Red.png`, `Amber.png`, `Green.png`: 상태별 확대 미리보기 (동일 접두어)

## 배치

기존 사거리의 루트가 (0,0,0)인 Blender 씬에서는 다음 배치를 사용할 수 있습니다. 보도 상단에 고정판이 놓이고 암이 차도 쪽으로 뻗습니다. 아래 좌표는 도로 규격을 바탕으로 계산했으며 사거리 조립 렌더는 이번 파일에 포함하지 않았습니다.

| 향하는 차량 | 원점 위치 (m) | Z축 회전 |
|---|---|---|
| 남쪽에서 진입 | (3.25,-6.8,0.158) | 0도 |
| 북쪽에서 진입 | (-3.25,6.8,0.158) | 180도 |
| 동쪽에서 진입 | (6.8,3.25,0.158) | 90도 |
| 서쪽에서 진입 | (-6.8,-3.25,0.158) | -90도 |

## 신호 변경

`Lens Red`, `Lens Amber`, `Lens Green` 오브젝트와 같은 이름의 재질을 분리해 두었습니다. Blender에서 켜질 렌즈의 Emission Strength를 3, 나머지는 0으로 설정하고 Base Color 밝기를 함께 조절하면 됩니다. GLB 세 개는 같은 모델의 서로 다른 점등 상태입니다.

Unity에서는 FBX를 배율 1로 가져오고 각 렌즈의 발광 재질을 사용하는 렌더 파이프라인에 맞게 설정하세요. GLB에는 별도 glTF 가져오기 기능이 필요합니다. Unity 내부 가져오기는 검증하지 않았습니다. 실제 교통 제어, 타이머, 차량 정지 로직, 자동 신호 전환은 포함하지 않았습니다.

발광 렌즈는 신호의 시각적 표현입니다. 도로를 밝히는 별도 광원은 포함하지 않았습니다. `Presentation` 컬렉션은 촬영용이며 FBX/GLB에서 제외했습니다. 충돌체는 엔진에서 별도 설정합니다.
