# SIM:US — 도로 표지판 6종 08

기존 가로등·신호등과 어울리는 청회색 기둥의 독립형 3D 표지판입니다. 높이 약 2.5~2.7m이며 고정판은 0.28 × 0.28m입니다.

| 파일 이름 부분 | 종류 |
|---|---|
| Speed30 | 속도 제한 30 |
| Stop | 정지 / STOP |
| NoEntry | 진입 금지 |
| OneWay | 일방통행 (정면에서 오른쪽 화살표) |
| Crosswalk | 횡단보도 |
| Parking | 주차 안내 |

## 제공 파일

- 각 종류별 `SIMUS_Sign_이름.glb`, `SIMUS_Sign_이름.fbx`: 원점에서 개별 배치하는 모델
- `SIMUS_Road_Signs_Collection.blend`: 6종을 나란히 놓은 편집 원본
- `SIMUS_Road_Signs_Preview.png`: 전체 모음
- `SIMUS_Road_Signs_Front.png`: 기호·문자 확인용 정면 이미지

외부 텍스처 없이 색상 재질과 메시로 표현했습니다. 글자는 메시로 변환해 글꼴 파일 없이 보입니다. 문구를 바꾸려면 기존 문자 메시를 새 텍스트로 교체해야 합니다. 판·기둥·기호는 별도 오브젝트입니다.

## 배치

각 GLB/FBX의 원점은 고정판 바닥 중앙이며 Blender에서 정면은 -Y입니다. 6종 모음 Blender 파일에서는 보기 쉽게 루트를 가로로 펼쳐놓았으므로 선택한 루트의 위치를 초기화한 뒤 배치하세요.

기존 직선 도로가 원점에 있을 때 보도 중심 X=±3.25m, Z=0.158m에 표지판을 놓을 수 있습니다. 글자 면이 접근하는 사람이나 차량을 향하도록 Z축 회전을 조정합니다. 일방통행 화살표는 정면에서 오른쪽을 향하며, 다른 진행 방향에는 판의 화살표 메시를 변경하거나 전체 배치 방향을 조정하세요.

Unity에서는 FBX를 배율 1, 1 unit=1m로 가져옵니다. 수평면이 XZ로 바뀌는 방향을 확인하세요. GLB는 glTF 가져오기 기능이 필요합니다. Unity 내부 가져오기는 이번 작업에서 검증하지 않았습니다. 충돌체·교통 규칙 적용은 별도 설정합니다.

이 표지판은 도시 게임용으로 단순화한 그래픽입니다. `Presentation` 컬렉션의 스튜디오 바닥·카메라·조명은 개별 GLB/FBX에 포함되지 않습니다.
