## 크기·통로·배치 기준
1 Unity유닛=1m. 바닥 중앙 피벗, Blender Z상향/-Y전면, Unity Y상향/+Z전면입니다. FBX 내부 축 변환을 초기화하지 말고 프리팹 최상위 Transform으로 배치하세요.
기둥 중심 간격2.8×2.6m, 천막 외형 약3.15×3.12×2.89m, 기본 카운터2.30×0.60m/높이0.92m, 게임 카운터0.75×0.60m/높이0.87m, 내부 테이블1.48×0.55m/높이0.78m입니다. 무게추·기둥은 지면에 닿고 테이블 다리는16mm매트 위에 놓입니다.
후면 우측 출입구 폭 약1m, 내부 카운터와 뒤 테이블 사이 약1.34m를 확보했습니다. 부스 배치 시 전면에1.5m 이상의 대기 공간을 별도로 예약해야 합니다. Anchor는 위치 안내이며 자동 NavMesh/대기열 예약 기능이 아닙니다. 앞쪽 Anchor(0,-2.1,0)는 Blender 좌표입니다.

## Unity 모듈·조명·충돌체
가림막3개, 카운터, 내부 테이블, 메인 간판, 메뉴판, 깃발, 줄 조명, 무게추, 바닥 매트, 전선 커버, 전용 소품이 루트 아래에서 분리되어 있습니다. 전체 부스 또는 FLAGS/STRING_LIGHTS를 SetActive로 전환하면 행복도 연출에 사용할 수 있습니다. 자동 행복도 연동 스크립트는 추가하지 않았습니다.
프레임 기둥4개, 카운터1개, 테이블1개, 천 패널3개로 총9개 단순 BoxCollider입니다. 카운터/패널을 끄면 해당 Collider도 함께 꺼집니다. 장식·소품에 세부 충돌체나 부스 전체를 막는 통짜 Collider를 만들지 않았습니다. 두 직원 Anchor는 충돌체 내부에 들어가지 않음을 Unity에서 확인했습니다.
LIGHT_ANCHOR_FRONT/INTERIOR/SIGN/STRING_LEFT/STRING_RIGHT를 제공합니다. FBX/프리팹에는 실시간 Light가 없고 발광 재질로 표시됩니다. 야간 Blender 미리보기는 전면 Anchor 위치에 프리뷰용 Area Light1개를 추가했습니다. 실제 주변을 밝히려면 Unity에서 필요한 소수의 Light를 Anchor에 추가하세요.
현재 프로젝트와 같은 Built-in Standard 재질이며 URP 프로젝트로 변경하면 재질 변환이 필요합니다. 메인 간판과 메뉴판 면은 별도 교체용 재질과 UV를 제공합니다. 메인 영문 글자는 별도 메시이므로 새 간판 텍스처를 사용할 때 해당 Letters 오브젝트를 끄세요.

## 검수 결과와 범위
모든 평가된 렌더 메시의 열린 경계/비다양체 가장자리0, 재질 누락0, 음수 스케일 없음. 본체 회전과 스케일 적용, 창고/맵 등의 다른 장면은 신규 Blender 원본에 포함하지 않았습니다. 저장본 재열기로 축제 장면1개/부스루트4개/내장 현수막 이미지/외부 이미지 누락0을 확인했습니다.
Unity6000.3.24f1에서 실제 FBX4개를 가져와 단위/크기/전면축/재질 및 텍스처/9개 충돌체/직원Anchor/패널·카운터 토글/인스턴스별 조명 그룹 독립 전환을 확인하고 Camera.Render로 프리뷰를 저장했습니다. 실제 게임 장면이나 코드, 기존 맵은 변경하지 않았습니다.
Blender 정면·좌우 사선·측면·후면·평면·성인 비교·장착부 확대·Anchor·야간 이미지와 Unity 렌더를 확인했습니다. 룰렛은 Blender24~72프레임에180도 회전하는 편집용 데모가 있고1/48/96프레임을 검사했습니다. FBX는 정적 모듈로 내보내며 Unity 플레이 동작은 구현하지 않았습니다.
LOD0 제공. 타깃기기 성능·실제 플레이어 캡슐 이동·군중/대기열·게임 이벤트 연결·풍압/물리 시뮬레이션은 후속 검수 대상입니다. 전체 삼각형 쌍 교차 전수검사는 하지 않았습니다. 메시/렌더/충돌체 검사를 전시 승인으로 표기하지 않으며 상태는 received입니다.
기존 캐릭터 관련 manifest 해시 불일치4행은 작업 전부터 있어 보존했습니다(baseline_errors.json). 이번 부스 항목의 해시와 경로 오류는 별도로 검사합니다.
