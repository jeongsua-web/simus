## 검사
Blender 재열기·FBX 재가져오기에서 치수 오차 2mm 미만, 재질 누락 없음, 음수 스케일 없음.
새 구조물 메시의 경계/노멀을 검사했습니다. 기존 통의 개방된 토폴로지는 원형 보존을 위해 유지했으며 Blender_Audit.json에 구분 기록했습니다.
5개 슬롯 × 기존 3개 상태 = 15개 상태 교체를 Unity에서 검사했습니다. 위치·높이·균일 크기가 유지되고 정상 통의 전면 방향도 확인했습니다.
기존 FBX의 가져오기 축/배율은 유지하면서 Unity 프리팹에 배율 1의 외부 루트를 추가해 교체 시 중복 확대를 방지했습니다.
원본 공유 재질을 변경하지 않는 조명 제어, 개별 슬롯 표시/숨김, 타공 알파 컷아웃, 8개 BoxCollider를 검사했습니다.
충돌은 기둥 4개·좌우 벽 2개·후면 1개·지붕 1개이며 전면 보행 공간에는 없습니다. MeshCollider는 사용하지 않습니다.
사람 크기 비교에는 기존 SIMUS_NPC_Cleaner(약 1.699m)를 배율 변경 없이 사용했고, NPC와 장비는 이미지에만 포함했으며 에셋에는 넣지 않았습니다.
정면·측면·후면·상부·연결부·통 배열·NPC 비교·구조물 전용·완성형·Unity 렌더를 확인했습니다.
