# SIM:US — 한국형 초록 도로 안내표지판 09

사용자가 제공한 두 참고 이미지의 초록 바탕, 흰 테두리, 한글·영문 병기, 노선번호와 화살표 구성을 반영한 3D 에셋 5종입니다. 기존 표지판 6종은 그대로 유지했습니다.

| 파일 이름 부분 | 종류 | 표시 예시 |
|---|---|---|
| Boundary | 경계 안내 | 강원도 / Gangwon-do |
| Distance | 거리 안내 | 서울 Seoul 143 km / 천안 Cheonan 57 km |
| Direction | 방향 안내 | 수원 Suwon / 신갈 Singal / 42 / 2 km |
| Junction | 분기 안내 | 서울 방면 Seoul / 고속도로 / 100 / 1.5 km |
| Gantry | 도로 위 문형 안내판 | 춘천·서종 / 화도 / 남양주·덕소, 노선 60·6 |

지명·거리·노선 조합은 참고 이미지 기반의 게임용 예시이며 실제 도로 경로를 검증한 안내 정보가 아닙니다.

## 제공 파일

- 각 종류별 `SIMUS_KGuide_이름.glb`, `.fbx`: 원점에 배치된 독립형 모델
- `SIMUS_Korean_Guide_Signs.blend`: 5종 모음 편집 원본
- `SIMUS_KGuide_Roadside_Preview.png`: 길가 표지판 4종 미리보기
- `SIMUS_KGuide_Gantry_Preview.png`: 대형 문형 안내판 미리보기

## 크기 및 배치

길가 표지판은 약 3.5~3.8m 너비, 전체 높이 약 4.1~4.3m인 두 기둥형입니다. 기존 1m 보도에는 크므로 부지 가장자리나 넓은 보도 공간에 배치하세요.

대형 문형 안내판은 기둥 중심 간격 11.3m, 전체 높이 약 8.5m입니다. 지면 원점에서 하부 가로대 아래까지 약 5.7m이며 도로 위 설치를 상정했습니다. 기존 도로 세트의 전체 폭 7.5m보다 넓으므로 양쪽 지주 공간을 별도로 확보해야 합니다.

각 GLB/FBX는 지면 중앙 원점, 정면 Blender -Y입니다. 모음 Blender 파일에서는 길가 표지판은 나란히, 문형 안내판은 뒤쪽에 배치했습니다. 실제 배치할 때 선택한 루트의 위치를 초기화한 뒤 이동·회전하세요.

## 편집 및 엔진 사용

표지판의 글자·화살표·테두리·노선 마크는 메시와 색상 재질로 만들었습니다. 외부 텍스처나 글꼴 파일 없이 표시됩니다. 글자는 메시로 변환했으며 오브젝트의 `source_text` 속성에 원문을 기록했습니다. 문구 변경 시 새 텍스트로 교체할 수 있습니다.

Unity에서는 FBX를 배율 1, 1 unit=1m로 가져오며 수평면이 XZ로 변환되는 방향을 확인하세요. GLB에는 별도 glTF 가져오기 기능이 필요합니다. Unity 내부 가져오기는 이번 작업에서 검증하지 않았습니다. 충돌체·내비게이션·교통 규칙은 별도 설정합니다.

`Presentation` 컬렉션은 촬영용입니다. 개별 FBX/GLB에는 스튜디오 바닥·카메라·조명을 넣지 않았습니다. 로고는 포함하지 않았습니다.
